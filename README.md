#  Biblioteca DDD

Aplicação Full Stack para gerenciamento de biblioteca, desenvolvida como desafio técnico utilizando:

- Backend em .NET 8
- Frontend em Angular
- SQL Server
- Arquitetura DDD
- Clean Code
- Entity Framework Core

---

#  Objetivo

A aplicação permite realizar o gerenciamento de livros de uma biblioteca, oferecendo funcionalidades de:

- Cadastro de livros
- Listagem de livros
- Atualização de registros
- Remoção de livros
- Filtragem de dados

O projeto foi desenvolvido aplicando conceitos de:

- Domain Driven Design (DDD)
- Clean Code
- SOLID
- Repository Pattern
- Dependency Injection

---

#  Tecnologias Utilizadas

## Backend

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Swagger

## Frontend

- Angular 19
- Angular Material
- TypeScript
- RxJS
