# Biblioteca DDD

Aplicação full stack para gerenciamento de livros, desenvolvida com:

- Backend em ASP.NET Core Web API
- Frontend em Angular
- SQL Server
- Arquitetura DDD
- Clean Code
- Entity Framework Core
- Angular Material

---

# Objetivo

A aplicação permite:

- Cadastro de livros
- Listagem de livros
- Filtro por título, autor e gênero
- Remoção de livros
- Interface moderna e responsiva

---

# Arquitetura

O backend foi estruturado utilizando princípios de:

- DDD (Domain Driven Design)
- SOLID
- Clean Architecture
- Repository Pattern
- Separation of Concerns
